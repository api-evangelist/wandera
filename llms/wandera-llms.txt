# Wandera (Jamf Security Cloud / RADAR)

> Wandera was a zero-trust mobile security company acquired by Jamf in July 2021. Its RADAR Risk API — served on api.wandera.com and documented on the Jamf Developer portal — lets security integrations query the risk state of enrolled devices and override device risk classifications. Authentication is a short-lived (15 minute) JWT obtained from an Application ID/Secret.

## APIs

- [Wandera RADAR Risk API](https://developer.jamf.com/jamf-security/docs/risk-api-2): Query and override device risk states. Base host https://api.wandera.com.
